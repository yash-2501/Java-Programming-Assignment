# How to Run

### 1. Install Java

Make sure Java JDK is installed.

Check the installation:

```bash
java -version
javac -version
```

### 2. Open the required assignment folder

```bash
cd Assignment-1
```

or

```bash
cd Assignment-2
```

### 3. Compile a program

```bash
javac Program1.java
```

### 4. Run the program

```bash
java Program1
```

Repeat the same steps for Program2.java through Program8.java.
