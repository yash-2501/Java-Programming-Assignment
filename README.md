# ⚙️ How to Run

## 1️⃣ Clone Repository

```bash

git clone https://github.com/yash-2501/Java-Programming-Assignment.git

```

## 2️⃣ Open Project

```bash

cd Java-Programming-Assignment

```

## 3️⃣ Navigate to Assignment

```bash

cd Assignment-1

```

or

```bash

cd Assignment-2

```

## 4️⃣ Compile a Program

```bash

javac Program1.java

```

## 5️⃣ Run the Program

```bash

java Program1

```

### 🧵 For Command-Line Arguments

```bash

java Program5 argument1 argument2

```

### 🌐 For TCP Client–Server

Run the **server first**, then start the client.
