# 🚀 How to Run

## 1️⃣ Install Java JDK

Make sure Java JDK is installed.

Check your installation:

```bash
java -version
javac -version
```

Expected:

```text
java version "..."
javac ...
```

---

## 2️⃣ Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Java-Programming-Assignment.git
```

Enter the repository:

```bash
cd Java-Programming-Assignment
```

---

## 3️⃣ Open an Assignment

For Assignment 1:

```bash
cd Assignment-1
```

For Assignment 2:

```bash
cd Assignment-2
```

---

## 4️⃣ Compile a Program

Example:

```bash
javac Program1.java
```

---

## 5️⃣ Run the Program

```bash
java Program1
```

You can repeat the same process for:

```text
Program1.java
Program2.java
Program3.java
Program4.java
Program5.java
Program6.java
Program7.java
Program8.java
```
